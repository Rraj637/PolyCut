🎯 Standard Workflow

The panel is ordered as a pipeline. Follow it top to bottom:

  1. Data Extraction — search a place (autocomplete suggestions included), select an extent (draw a rectangle or use the current map extent, max 100 km²), pick a data source (live API or cached local dataset), choose the measurement CRS (UTM auto-detect or manual override).
  2. Layers — toggle layer visibility, build the Composite Map, and use local preview (click any feature to inspect it).
  3. Category boxes (Road / Building / Water / Natural & Land Use) — extract, buffer (m / mm / cm / km / ft), dissolve.
  4. GIS Tools — professional digitizing: select, move, vertex-edit, draw point/line/polygon, split, merge, delete — on digitized and extracted layers.
  5. Plugins — load JS processing plugins (two built-ins ship with the app).
  6. Export — GeoJSON / SHP / SVG per dataset, map-view PDF / PNG, or Download All (ZIP) for everything at once.

⚡ Extract All (one click)

The Extract All button issues a single Overpass request for all categories, caches the result, and instantly populates Road, Building, Water and Natural & Land Use with your current sub-category filters. If the same extent was downloaded before, the server cache is reused (no new API call). The source mode switches to Local automatically.

💾 Local Data & Persistence

  • Download Extent Data (Cache) — one request downloads everything for the extent to the server cache (local_cache/). Extraction from it is instant and repeatable.
  • Browser storage persistence — every downloaded dataset is also saved to IndexedDB in your browser. After a page reload the most recent dataset is restored automatically, and any saved dataset can be reloaded from Saved datasets → Load.
  • Clear Server Cache — deletes all cached JSON from the server and the browser copies (frees disk).
  • Saved datasets 🗑 — removes only the selected saved copy from browser storage.
Local preview (Layers panel) renders the cached dataset on the map — click any feature to highlight it and read its attributes. No re-extract needed; toggle the checkbox off to remove the preview.

🧮 Snapping (0–100 slider)

  • Vertex snap — targets include every loaded layer: extracted roads/buildings/water/natural, buffers, dissolved, composite and digitized features. The nearest vertex within tolerance shows a magenta dot.
  • Edge snap — projects the cursor onto the nearest segment of any polygon/line (precise joins between vertices).
  • Tolerance slider (Data Extraction panel, below Extract All): 0 = off, 100 = very strong. 12 px is a good default; raise it for coarse data, lower it in dense areas.
Zoom controls real-world accuracy: at z18, 12 px ≈ 0.6 m; at z19 ≈ 0.3 m.

📈 CRS / UTM Control

All measurements (length, area, buffers) are computed in a UTM projection for meter-accurate results. Auto-detect picks the correct zone for the extent. The UTM Zone + hemisphere selects let you force any zone worldwide (e.g. cross-border or custom projects) — the override applies to the EPSG label shown under the extent and to server-side buffer operations.

🔧 GIS Tools (Digitizing)

Editing operates on every loaded layer — digitized features and extracted datasets. Edits stay in the source layer and are included in exports automatically.

ToolBehaviour
SelectClick a feature = select. Shift+click = multi-select. Drag the selected feature = move it. Drag the cyan handles = edit vertices (live preview, geodesic metrics recomputed).
PointOne click places the point (snapped if enabled).
Line / PolygonClick = vertex; Enter or double-click = finish; click the first vertex (snap dot) to close a polygon. Live length/area readout while sketching.
SplitSelect ONE polygon, activate Split, draw a cutting line past both boundaries, Enter. Server-side Shapely split — planar-exact; pieces stay in the source layer.
Merge2+ selected: same type = real dissolve (union for polygons, Multi* for lines/points) — in-source if all from one layer, otherwise into the Composite. Mixed types = moves the selection into the Composite map (src records origin).
DeleteDel or the button; undoable.
Finish / CancelEnter / Esc.
Every operation is captured by Undo/Redo. Extracted-layer edits also update the layer's stored dataset — export includes them.

🗺 Composite Map (merge across categories)

The Build Composite Map button (Layers panel) compiles all visible category layers + digitized features into a single FeatureCollection:

  • Original OSM IDs, names and attributes are preserved.
  • Each feature gains a src attribute recording its origin layer (road, building, water, nature, digitized).
  • The composite appears as a pink layer and as composite-map in the Export panel and Download All ZIP.

For a hand-picked map: Shift+click features across different layers, then Merge — they move into the Composite with their IDs intact.

📦 Export

  • GeoJSON / SHP / SVG — the selected category+stage (Base / Buffer / Dissolved / Composite Map). SHP ZIP includes .shp/.shx/.dbf/.prj (WGS 84).
  • PDF / PNG — current map view capture.
  • Download All (ZIP) — every dataset that exists: all categories × stages, composite map, digitized features. Each in its own folder with GeoJSON + Shapefile set + SVG + a README manifest.

🔌 Plugin Development

Plugins are JavaScript files that call GISPlugin.register(). Two built-ins ship with the app (Multipart Split — QGIS "Multipart to Singleparts" equivalent, and Feature Reporter); user plugins load via file or URL and persist in localStorage.

Plugin skeleton

GISPlugin.register({
  id: 'my-plugin',              // unique id (required)
  name: 'My Plugin',            // display name (required)
  version: '1.0.0',
  author: 'Your Name',
  description: 'What it does',
  tools: [
    {
      id: 'my-tool',
      label: '🔧 My Tool',   // button text in the Plugins panel
      run(ctx) {
        ctx.toast('Hello from plugin!');
      },
    },
  ],
});

Example — transform every layer

GISPlugin.register({
  id: 'my-cleaner',
  name: 'Geometry Cleaner',
  version: '1.0.0',
  author: 'You',
  description: 'Drops properties from all loaded layers',
  tools: [{
    id: 'strip',
    label: '🧹 Strip Properties',
    run(ctx) {
      ctx.editableCollections().forEach((col) => {
        col.fc.features.forEach((f) => { f.properties = { osm_id: f.properties.osm_id }; });
      });
      ctx.pushHist();
      ctx.render();
      ctx.toast('Properties stripped (osm_id kept).');
    },
  }],
});
Plugin code runs with full page privileges (same trust model as QGIS/ArcGIS plugins). Load only your own or trusted code. For heavy geometry work, extend the Flask server (app.py) with a new /api/... endpoint — /api/gis/split is a reference implementation — and call it via ctx.api().
